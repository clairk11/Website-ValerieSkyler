# Noa Rive — Website

Vite + React + TypeScript + Tailwind CSS. A clone of the
[soundform.framer.website](https://soundform.framer.website/) artist template
("Noa Rive - Afro house artist").

## Development

```bash
npm install
npm run dev
```

## Structure

- `src/pages/Soundform/SoundformPage.tsx` — the site: nav, hero, selected
  music, live dates, watch/video, newsletter, about, and footer sections.
- `src/pages/Soundform/data.ts` — track list, live dates, and about-gallery
  content.
- `public/media/soundform/` — downloaded imagery from the source site.
